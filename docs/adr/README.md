# Architecture Decision Records

One file per decision, numbered, never rewritten: a superseded ADR gets a `Superseded by`
line and stays. Anything in `CLAUDE.md` marked as a decision (§3, §4) holds until an ADR
here changes it (CLAUDE.md §10).

Template:

```markdown
# ADR-NNNN: <title>

- Status: proposed | accepted | superseded by ADR-MMMM
- Date: YYYY-MM-DD

## Context
## Decision
## Alternatives considered
## Consequences
```
